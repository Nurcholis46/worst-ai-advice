A make.fun entry: a program that writes one line of the worst possible advice an AI could give — in the confident, tidy voice of a real AI assistant, specific enough to follow and terrible enough to make you wince.

The line (98 characters):

> If your car brakes squeak, spray WD-40 on the brake discs — squeaking means they need lubrication.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

It writes `entry.txt` into the output directory, checks the gate itself (1–140 characters, not only whitespace, a single line), chmods the file to 0644, and verifies the write by reading it back.
